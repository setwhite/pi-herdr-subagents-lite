# T05 unknown 与结果读取失败

- [x]

## 交付物

轮询看到 getAgent 返回 null、连续 3 次轮询错误、或完成后 3 次读取仍无文本时，投递唯一一条 unknown 结果（reason + Session 路径），保留 tab，释放槽；session_shutdown 后不再投递。连续错误在成功一次后清零。

起点：T04 后没有 unknown 路径和 shutdown 停止，AC1–AC5 红；AC6 是 T03/T04 回归，保持绿。

## 验收

- AC1：`test/extension.test.ts::reports missing agent as unknown`：首次轮询 getAgent 返回 null；推进 1000ms；恰好一条 unknown，正文含 unknown (agent_missing) 和 Session: <sessionFile>；close 0；之后推进不再发消息；下一次 run 能成功。
- AC2：`test/extension.test.ts::reports three consecutive poll failures`：getAgent 连续抛错 3 次；第 3 次后一条 unknown (poll_failed)；第 4 次推进不再发消息；close 0。
- AC3：`test/extension.test.ts::resets poll failure count on success`：前两次抛错、第三次返回 idle/1，fixture 有文本；只收到 done，不收到 unknown；close 一次。
- AC4：`test/extension.test.ts::reports unreadable result as unknown`：完成信号后 session 为空；推进 1000ms 仍无消息；再推进 400ms 出现一条 unknown (no_result)，含 Session 路径；close 0；下一次 run 能成功。
- AC5：`test/extension.test.ts::stops after session shutdown`：run 后调用 session_shutdown；推进 5000ms；send 0，close 0。
- AC6：T03/T04 用例保持通过；`pnpm check` 通过。
