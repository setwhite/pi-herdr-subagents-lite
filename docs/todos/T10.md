# T10 全局 profile 与 run 的 profile 参数

- [x] 已完成

## 交付物

`<agent-dir>/agents/*.md` 解析成 profile 列表：frontmatter 与 body 分离，字段按 spec §2 校验，未知字段忽略。工具参数从 `{action:"run", task}` 改成 `{action:"run", profile, task}`。profile 不存在返回 `unknown_profile` 并列出可用名字；文件在但字段坏返回 `profile_invalid` 并指出文件与字段。新模块 `profile` 进 `docs/ARCHITECTURE.md` §1、§2 与 `scripts/check-imports.mjs`；frontmatter 用 pi 导出的 `parseFrontmatter`，因此 pi 允许在 `src/profile` 做运行时 import。

起点：`run` 只认 `task`，AC1–AC4 红。

## 验收

- AC1：`pnpm vitest run test/profile.test.ts` 通过：frontmatter 与 body 分离；`skills: a` 与 `skills: [a, b]` 都成列表；`skills: ""` 成空列表；未知字段不报错；无 frontmatter 时 body 即全文。
- AC2：`pnpm vitest run test/extension.test.ts -t "starts a run with a global profile"`：`agents/explore.md` 存在时 `run({profile:"explore",task})` 返回 `{"state":"running",...}`。
- AC3：`-t "lists profiles on unknown profile"`：`run({profile:"nope"})` 返回 `unknown_profile`，文本含 `explore`。
- AC4：`-t "reports invalid profile"`：`explore.md` 写 `thinking: sometimes`；`run({profile:"explore"})` 返回 `profile_invalid`，文本含文件名与 `thinking`。
- AC5：`pnpm check` 通过；`check:imports` 的 `typeOnlyIn` 已把 pi 的运行时 import 限定在 `src/index.ts` 与 `src/profile/index.ts`。
