## 交付物

在 HERDR_ENV=1 下，run 为任务创建唯一 run root、写 brief、开不抢焦点 tab、以 worker-N 启动 pi 子进程，返回 running；最多 4 个活跃 worker，第 5 个返回 max_concurrent。还不轮询、不投递结果。

起点：T01 后 run 在 herdr 内只返回未实现错误，AC1–AC3 红；AC4 是 T01 回归，保持绿。

## 验收

- AC1：`test/extension.test.ts::launches a worker`：run 返回 state running、name worker-1；fake host 的 createTab 收到父 cwd 和 label worker-1，startAgent 收到同一 pane、session/brief 路径；brief 文件存在且包含任务文本和 worker 指令。
- AC2：`test/extension.test.ts::rejects the fifth active worker`：连续 4 个 run 成功；第 5 个返回 isError，code max_concurrent，文本含 worker-1 到 worker-4；createTab 仍为 4 次。
- AC3：`test/extension.test.ts::uses distinct child sessions`：同一服务第二次 run 的 sessionFile 与第一次不同，name 为 worker-2。
- AC4：T01 的 not_in_herdr 与 schema 用例保持通过；`pnpm check` 通过。
