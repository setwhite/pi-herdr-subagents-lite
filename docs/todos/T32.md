## 交付物

`HerdrHost.createWorkspace({ cwd, label })`（`workspace create --cwd --label --no-focus`）。profile 的 cwd 与父 cwd 不同时，先建 workspace 再 `tab create --workspace`；相同则只建 tab（D22）。

## 验收

- AC1：`-t "creates a workspace when the cwd differs"`：`createWorkspace` 1 次，`tab create` 带该 workspace id。
- AC2：`-t "uses the current workspace for the parent cwd"`：0 次。
- AC3：`pnpm check` 通过。
