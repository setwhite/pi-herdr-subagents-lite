## 交付物

真实 herdr CLI 适配器：createTab/startAgent/getAgent/closeTabIfOnlyPane 用 execFile argv，解析 JSON，映射错误；index 装配真实适配器。隔离环境中用 pi -e 加载构建产物，跑通一个正常 worker 的完整闭环，并验证反问留在子 pane、父侧不转发。

起点：T06 后 index 仍没有真实 CLI 适配器，AC2–AC3 无法执行；AC1 是既有 QA，保持绿。

## 验收

- AC1：`pnpm check` 通过；`pnpm build` 生成 dist/index.js；package.json 的 pi.extensions 指向它。
- AC2：手工 E2E（按 spec 的手工 E2E 正常路径）：使用隔离的 PI_CODING_AGENT_DIR（复制 auth、最小 settings、不加载旧包）和命名 herdr session；在 herdr pane 内运行 pi -e dist/index.js；调用 subagent.run 派发只读任务；观察到 running 返回、新 tab、子 pi、一条 [subagent worker-1] done 结果、tab 关闭、agent list 无 worker-1。
- AC3：手工反问（若子环境有 ask_user_question）：派发一个会提问的短任务；问题只出现在子 pane；父会话没有转发或 answer 消息；人在子 pane 回答后，父会话只收到最终 done。若 ask 不可用，记录原因并确认父侧没有 answer 工具。
- AC4：E2E 记录命令与关键输出（worker name、pane、sessionFile、结果首行）；失败时记录 herdr 原始错误。
