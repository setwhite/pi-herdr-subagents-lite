## 交付物

工具注册从扩展加载期移到 `session_start`；`toolName` 决定注册名，`enabled: false` 不注册。description / snippet / guidelines 默认取 PROMPTS.md，`{{profiles}}` 展开为 profile 列表（name 加 description），`{{toolName}}` 展开为注册名；`prompts` 三个键覆盖默认，`snippet: ""` 让工具从 Available tools 消失。

起点：注册发生在工厂调用时，`toolName` 与 `prompts` 无效果，AC1–AC4 红。

## 验收

- AC1：`-t "registers the tool at session start"`：工厂返回时不注册；发 `session_start` 后注册一次。
- AC2：`-t "honors tool name"`：`{"toolName":"helper"}` → 注册名 `helper`；`Helper`、`1x`、33 字符三个非法名按 T09 的错误路径不注册。
- AC3：`-t "skips registration when disabled"`：`{"enabled":false}` → `registerTool` 0 次。
- AC4：`-t "expands profiles in guidelines"`：默认文案里 `{{profiles}}` 变成 `explore — <description>` 行；`prompts.guidelines: ["Use {{toolName}}"]` 覆盖后为 `Use subagent`；`prompts.snippet: ""` 时注册的 snippet 为空串。
- AC5：`pnpm check` 通过。
