## 交付物

死亡分支读回执：有回执且 session 尾部有最终文本 → `done`；有回执无文本 → `unknown (quitted)`；无回执 → `unknown (pane exited)`。`UnknownReason` 增加 `quitted`、`pane_exited`。已经投递过的 run 不因回执重复投递。

## 验收

- AC1：`-t "reports a quitted run when the receipt has no final answer"`。
- AC2：`-t "reports pane exited without a receipt"`。
- AC3：`-t "does not repeat a delivered run"`：投递后出现回执 → `sendMessage` 仍 1 次。
- AC4：`pnpm check` 通过。
