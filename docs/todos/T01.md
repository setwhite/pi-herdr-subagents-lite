# T01 可加载的 subagent 工具

- [x]

## 交付物

最小 ESM package 能构建并被测试加载；注册唯一工具 subagent，参数只有 action:"run" 和 task；非 herdr 环境返回 not_in_herdr，HerdrHost 零调用。HERDR_ENV=1 的启动路径留到 T02。

工具 schema、promptSnippet、description、guidelines 按 spec「工具契约」；package scripts 按 spec「package 与 QA」。

起点：没有 package.json 和 test/extension.test.ts，AC1–AC4 均失败。

## 验收

- AC1：`pnpm check` 通过；`pnpm build` 生成 `dist/index.js`，`package.json` 的 `pi.extensions` 指向它。
- AC2：`pnpm test` 的 `test/extension.test.ts::registers the subagent schema` 断言工具名 subagent、label Subagent、schema 只有 action/task、required 两者、additionalProperties false。
- AC3：`test/extension.test.ts::rejects outside herdr` 在 HERDR_ENV 未设置时调用 run，返回 isError，文本以 not_in_herdr 开头，fake host 调用次数为 0。
- AC4：`test/extension.test.ts` 的 prompt 断言 description/promptSnippet/guidelines 含 background worker、asynchronously、subagent_result 三个关键词。
