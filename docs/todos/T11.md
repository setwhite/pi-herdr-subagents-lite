# T11 profile 变成子进程参数

- [ ] 未开始

## 交付物

profile 字段落成子进程 argv：`--model`、`--thinking`、`--tools`（含 `+name` / `-name` 形式与 `--no-tools`）、`--no-skills` 加 `--skill`、`--append-system-prompt` / `--system-prompt`、tab 的 `--cwd`。`system-prompt: task` 时不传参数，profile body 拼在简报前。身份文件写 `<childSession>.identity.md`。`HerdrHost.startAgent` 改成接收 `agentArgs`，argv 顺序为 `agent start <name> --kind pi --pane <id> --timeout 30000 -- --session <file> <agentArgs...>`。

起点：`startAgent` 只传 `--session`，AC1–AC5 红。

## 验收

- AC1：`-t "passes model and thinking"`：`model: opencode-go/x`、`thinking: high` 时 argv 含 `--model` `opencode-go/x` `--thinking` `high`。
- AC2：`-t "maps tools"`：`read,bash` → `--tools read,bash`；`+read,-subagent` → `--tools +read,-subagent`；`""` → `--no-tools`。
- AC3：`-t "maps skills"`：`[a, b]` → `--no-skills --skill <agent-dir>/skills/a --skill <agent-dir>/skills/b`；省略时 argv 不含 `--skill` 与 `--no-skills`。
- AC4：`-t "writes the identity file"`：默认（append）时 `<childSession>.identity.md` 内容等于 profile body 且 argv 含 `--append-system-prompt <该路径>`；`replace` 换成 `--system-prompt`；`task` 时不写身份文件、不传参数，简报首段含 profile body。
- AC5：`-t "uses the profile cwd"`：`cwd: sub` 时 `createTab` 收到 `<父 cwd>/sub`；省略时收到父 cwd。
- AC6：`pnpm check` 通过。
