# T04 启动失败与 name_taken

- [x]

## 交付物

启动链失败时返回 spawn_failed，保留已创建 pane，不投递结果，释放槽；agent_not_ready 的文本提示去 pane 处理 trust；name_taken 时用下一个 worker-N 重试（初始 + 最多 3 次重试），仍失败返回 spawn_failed。成功 launch 行为不变。

起点：T03 后启动异常会冒泡或挂起，AC1–AC4 红；AC5 是 T02 回归，保持绿。

## 验收

- AC1：`test/extension.test.ts::reports createTab failure`：createTab 抛错；run 返回 isError，code spawn_failed，文本含底层错误；startAgent 0 次，sendMessage 0 次，close 0 次；下一次 run 能成功。
- AC2：`test/extension.test.ts::reports startAgent failure with pane`：createTab 成功、startAgent 抛 agent_not_ready；run 返回 spawn_failed，文本含该 paneId 和 trust；close 0，sendMessage 0；下一次 run 能成功。
- AC3：`test/extension.test.ts::retries name_taken with next worker`：第一次 startAgent 抛 name_taken、第二次成功；run 返回 running、name worker-2；createTab 一次，startAgent 两次，无结果消息；renameTab 收到 worker-2；两次 startAgent 的 sessionFile 与 briefFile 保持不变。
- AC4：`test/extension.test.ts::gives up after three name_taken retries`：初始 + 3 次重试都 name_taken；run 返回 spawn_failed；startAgent 4 次，close 0，sendMessage 0，下一次 run 能成功。
- AC5：T02 的第五个 max_concurrent 用例保持通过；`pnpm check` 通过。
