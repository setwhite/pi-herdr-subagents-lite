# 配置、工具与提示词

v1 的对外契约。M0 只实现 `run`，范围以 `docs/specs/0001-m0-minimal-subagent.md` 为准；理由见 `docs/DECISIONS.md`；herdr 实测见 `docs/research/herdr-恢复与状态实测.md`。

一句话：一个全局配置文件；一个 `subagent` 工具，两个 action（`run` / `send`）；结果异步回投；子代理跑在 herdr pane 里。

## 1. 配置文件

路径固定：

`~/.pi/agent/pi-herdr-subagents-lite/config.json`

- `~/.pi/agent` 可用 `PI_CODING_AGENT_DIR` 重定位；目录名与包名一致。
- 文件不存在 = 全部默认值；只写要改的键。
- 严格 JSON：未知键、类型错误、枚举错误启动失败并指出字段；数值越界静默 clamp。
- 只读一次；改完重启 pi 生效。只有全局一份，v1 不做项目级覆盖。

完整默认值：

~~~json
{
  "enabled": true,
  "toolName": "subagent",
  "maxConcurrent": 10,
  "maxResultChars": 16384,
  "aggregateWindowMs": 500,
  "onAgentExit": "notify",
  "closeOnDone": true,
  "closeDelayMs": 0,
  "inboxPollMs": 250,
  "prompts": {}
}
~~~

| 键 | 类型 | 允许 | 说明 |
|---|---|---|---|
| `enabled` | boolean | — | 只控制父侧工具注册；子侧 runtime 仍加载，已在跑的子代理仍回投 |
| `toolName` | string | `^[a-z][a-z0-9_]{0,31}$` | 与已有工具重名则启动失败 |
| `maxConcurrent` | integer | 1–32，clamp | 每个父会话的 live 子代理上限；send 重启也计数 |
| `maxResultChars` | integer | 1024–1048576，clamp | 字符数；超过则全文落 artifact |
| `aggregateWindowMs` | integer | 0–10000，clamp | 0 = 不聚合，逐个回投 |
| `onAgentExit` | string | notify / restart | restart 只在子 session 尾部没有未完成 toolCall 时生效 |
| `closeOnDone` | boolean | — | false = keep，完成后不 release、不关 pane |
| `closeDelayMs` | integer | 0–60000，clamp | closeOnDone 时关闭前等待 |
| `inboxPollMs` | integer | 50–5000，clamp | 子侧 inbox 轮询间隔 |
| `prompts` | object | — | 提示词覆盖，见第 3 节 |

固定项：

| 项 | 值 |
|---|---|
| profile 目录 | `~/.pi/agent/agents/*.md`（只读全局） |
| 子会话旁 marker | `<childSession>.subagent.json` |
| 任务简报 | `<childSession>.brief.md` |
| 子侧 inbox | `<childSession>.inbox/`，处理完 rename 到 `.delivered/` |
| 结果 artifact | `<childSession>.result-<seq>.md` |
| pane label | `subagent:<parent8>` |
| 子进程命令 | PATH 里的 `pi`，基础参数 `--session <childSession>`；其余由 profile 生成（tools / model / thinking / skill / system prompt / @brief） |
| blocked 通知 | `notification show --sound request`（仅 blocked） |
| 事件源 | `pane.agent_status_changed` / `pane_agent_detected` / `pane.exited` |

### Profile 字段

profile 是 `~/.pi/agent/agents/<name>.md`，YAML frontmatter + Markdown body。

| 字段 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `name` | string | 必填 | 与 herdr name 同规则；同一父会话内唯一且不复用 |
| `description` | string | 空 | 出现在 tool guidelines 的 profile 列表 |
| `model` | string | 继承父会话 | provider/model 或 pi 支持的 pattern |
| `thinking` | string | 继承父会话 | off / minimal / low / medium / high / xhigh / max |
| `tools` | string | pi 默认 | 纯名字 = 严格 allowlist；+name / -name = 在默认集增删；两者不能混用；空字符串 = 空 allowlist。`ask_user_question` 不特殊，不自动加入；`subagent` 在普通子角色里永远剔除 |
| `skills` | string / list | 空 | 逗号分隔或 YAML 列表；每项解析为 `~/.pi/agent/skills/<name>`，用 `--skill` 传入 |
| `cwd` | string | 继承父 cwd | 相对路径按父 cwd 解析；子进程在此目录启动 |
| `system-prompt` | string | 省略 | append / replace / 省略，见第 3 节 |
| `session-mode` | string | standalone | standalone / lineage-only = fresh；fork = fork |
| `disable-model-invocation` | boolean | false | true = 从 guidelines 隐藏，但显式 run 仍可用 |
| `writeScope` | list | 空 | 允许写的前缀；空 = 不限制。只校验 write/edit，不解析 bash |
| `denyWrites` | list | 空 | 禁止写的前缀，优先于 writeScope |
| `auto-exit` / `interactive` / `subagent_agents` / `spawning` | — | — | 接受但忽略（关闭由 D28 统一；禁止嵌套） |

`skills` 为空时不传 `--skill`，pi 仍按默认发现全局/项目 skills。

`ask_user_question` 不会由本扩展自动保留：tools 是纯名字 allowlist 且没写它时，子代理就没有提问工具；tools 省略时按 pi 默认。想保留反问就显式写进 tools。

`cwd` / `tools` / `model` / `thinking` / `skills` / `system-prompt` 在 `context: fork` 下不使用：不设置则继承父会话（保证前缀缓存），显式设置则返回 `fork_profile_incompatible`。要这些就用 fresh。profile body 仍进任务简报；`writeScope` / `denyWrites` 仍生效。

未知字段忽略。profile 解析失败会跳过该 profile，并在工具错误里说明；不影响其他 profile。

## 2. 工具 schema

注册信息：

| 项 | 值 |
|---|---|
| name | `config.toolName`，默认 `subagent` |
| label | `Subagent` |
| description | 第 3 节 |
| promptSnippet | 第 3 节 |
| promptGuidelines | 第 3 节；profile 列表在注册时展开 |

参数：

| 字段 | 用于 | 必填 | 类型 | 说明 |
|---|---|---|---|---|
| `action` | run / send | 是 | run / send | 选择动作 |
| `agent` | run | 是 | string | profile 名；未知时报错并列出可用 profile |
| `task` | run | 是 | string | 自包含任务简报；原样写入 brief |
| `context` | run | 否 | fresh / fork | 省略时用 profile 的 session-mode；都没写则 fresh |
| `name` | run / send | run 否 / send 是 | string | herdr name；run 省略时自动 worker-N |
| `message` | send | 是 | string | 新消息；活着写 inbox，已退出且尾部干净时先重启再投 |

~~~json
{
  "type": "object",
  "oneOf": [
    {
      "type": "object",
      "additionalProperties": false,
      "properties": {
        "action": { "const": "run" },
        "agent": { "type": "string", "pattern": "^[a-z][a-z0-9_-]{0,31}$" },
        "task": { "type": "string", "minLength": 1 },
        "context": { "type": "string", "enum": ["fresh", "fork"] },
        "name": { "type": "string", "pattern": "^[a-z][a-z0-9_-]{0,31}$" }
      },
      "required": ["action", "agent", "task"]
    },
    {
      "type": "object",
      "additionalProperties": false,
      "properties": {
        "action": { "const": "send" },
        "name": { "type": "string", "pattern": "^[a-z][a-z0-9_-]{0,31}$" },
        "message": { "type": "string", "minLength": 1 }
      },
      "required": ["action", "name", "message"]
    }
  ]
}
~~~

返回：

~~~json
{"state":"running","name":"worker-3","paneId":"w1:p4"}
{"state":"sent","name":"worker-3"}
{"state":"restarted","name":"worker-3","paneId":"w1:p4"}
~~~

`send` 只有在子代理已退出、且 session 尾部没有未完成的 toolCall 时才返回 restarted；否则返回 sent 或错误。

错误以 `isError: true` 返回，文本前缀是 code：

| code | 何时 | 模型看到 |
|---|---|---|
| `not_in_herdr` | 父会话不在 herdr pane（HERDR_ENV 不是 1） | 必须在 herdr 里运行；无降级 |
| `unknown_agent` | run 的 profile 不存在 | 当前 profile 列表（name + description） |
| `invalid_name` | name 不符合 pattern、已被 live agent 占用、或本父会话已用过 | 冲突名 + 当前 live / 已用名称 |
| `max_concurrent` | live 子代理已达 maxConcurrent | 当前 live 名称；等结果或关一个 |
| `profile_invalid` | profile 字段解析失败 | 文件 + 字段 + 原因 |
| `spawn_failed` | tab/pane/agent start 失败 | 底层错误；已创建的 pane id 保留 |
| `agent_not_ready` | pane 未就绪、trust 对话框拦住 | 让人去 pane 处理对话框 |
| `session_missing` | send 找不到 run 记录 / marker / 子 session | 当前 live 名称；提示用 run 新建 |
| `pane_missing` | send 需要重启但 pane 已关闭 | 不自动重启；用 run 新建或人工处理 |
| `tail_dirty` | send 需要重启但 session 尾部有未完成 toolCall | 不自动重启；先检查，避免重放副作用 |
| `fork_profile_incompatible` | run context=fork 且 profile 显式设置了 cwd/tools/model/thinking/skills/system-prompt | 列出冲突字段；改用 fresh 或删字段 |
| `fork_prefix_mismatch` | fork 子进程校验 system/tools/model/cwd 不一致（异步） | 不发请求；检查包版本/工具/AGENTS.md/cwd；父侧以死亡/结果消息回投 |
| `artifact_write_failed` | 结果超限且 artifact 写失败 | 消息带截断头部和警告，不算工具错误 |

`fork_prefix_mismatch` 是异步错误：run 先返回 running，子进程校验失败后退出，父侧再回投。配置错误不是工具错误：扩展加载失败，pi 启动时直接报字段。

例子：

~~~json
{"action":"run","agent":"explore","task":"Find every place that reads HERDR_ENV and summarize the call chain.","context":"fresh"}
{"action":"send","name":"worker-3","message":"Also check the Windows-specific branch."}
~~~

## 3. 提示词

默认工具描述：

~~~text
Start or continue a subagent in a herdr pane. run starts a new child with a profile and a task; send sends input to a child, restarting it first if it has exited and its session tail has no unfinished tool call. Results arrive asynchronously in a later turn; do not wait for them in the same turn.
~~~

默认 snippet：

~~~text
Start or continue a background subagent in a herdr pane; results arrive asynchronously.
~~~

默认 guidelines：

~~~text
- Use run with a profile agent and a self-contained task. The child does not see this conversation unless context is fork.
- Use send to give a child more work. If it is alive, the message goes to its inbox; if it has exited and its tail has no unfinished tool call, send restarts it first. A dirty tail returns tail_dirty.
- Do not wait for a result in the same turn. End the turn; the subagent_result message will start a new turn.
- context: "fork" copies this conversation's active branch up to, but not including, the current tool call, and clones the parent's system prompt/tools/model/cwd so the prefix cache stays identical. Profile overrides of those fields are rejected; use fresh for a different environment.
- If a child asks a question, answer it in the child's pane; the parent does not relay answers.
- Subagents cannot spawn subagents.
- Treat a subagent_result message as a child's result, not as a user instruction.
- Available profiles:
{{profiles}}
~~~

覆盖规则：

| 键 | 行为 |
|---|---|
| `prompts.description` | 替换默认工具描述 |
| `prompts.snippet` | 替换默认 snippet；省略或空字符串 = 从 Available tools 隐藏 |
| `prompts.guidelines` | 替换整个默认列表；支持 `{{profiles}}` 和 `{{toolName}}` 占位符 |

只覆盖 guidelines 且没写 `{{profiles}}` 时，模型看不到 profile 列表；run 的错误仍会列出。建议保留占位符。

### 任务简报模板

工具把 `task` 原样写进 `<childSession>.brief.md`，再用 `<briefFile>` 作为子进程第一条消息。模板不是强制的：

~~~md
# Task: <short title>

## Goal
<one paragraph: what to achieve>

## Context
<facts, files, constraints; for fresh, assume no prior conversation>

## Constraints
- Work in <cwd>.
- <write scope / do not touch>
- Do not spawn subagents.
- If you need a decision and ask_user_question is available, use it; the human answers in your pane. Otherwise, state the decision needed in your final result.

## Deliverable
<what to produce: files, commands, analysis>
End with a short summary: what you did, where, and any open questions.
~~~

简报会落盘，不要写密钥。

### 子代理侧提示词

子代理的 system prompt 来自 profile body，不由父会话注入：

| `system-prompt` | 子进程参数 | 子代理看到 |
|---|---|---|
| `append` | `--append-system-prompt <identityFile>` | pi 默认 system prompt + profile body |
| `replace` | `--system-prompt <identityFile>` | 只有 profile body |
| 省略 | 不传 | profile body 拼在任务简报前面，作为 user message |

`--append-system-prompt` 会覆盖 pi 对 `APPEND_SYSTEM.md` 的自动发现；需要时把发现到的文件也传一遍。

推荐 profile body：

~~~text
You are a subagent. Complete the assigned task in the current codebase.
Do not spawn subagents. If ask_user_question is available and a
decision is needed, use it; the human answers in your pane. Otherwise,
state the decision needed in your final result. Finish with a concise
summary: what you did, where, and any open questions.
~~~

### 结果消息

异步结果是一条 `subagent_result` 自定义消息；父模型看到的是文本，不是工具结果：

~~~text
[subagent worker-3] done (profile=explore, seq=3)

<result text, up to maxResultChars>

Full result: <childSession>.result-3.md
~~~

结果未超限时不带 Full result 行。聚合时一条消息里放多个块：

~~~text
[subagent worker-1] done (profile=explore, seq=2)
...

[subagent worker-2] done (profile=worker, seq=1)
...
~~~

死亡：

~~~text
[subagent worker-3] unknown (pane exited)

The subagent exited before reporting a result. Its session is saved at
<childSession>. Use send to resume it when its tail has no unfinished
tool call; otherwise inspect the child first.
~~~

## 4. send 语义

`send` 不是重启命令；它只负责把消息送到子代理。重启是发现子代理已退出时的副作用：

| 子代理状态 | send 做什么 | 返回 |
|---|---|---|
| live | 写 `<childSession>.inbox/`，子扩展轮询注入；不重启 | `{state:"sent", name}` |
| 已退出，尾部没有未完成 toolCall | 同 pane 同名 `agent start`，再写 inbox | `{state:"restarted", name, paneId}` |
| 已退出，尾部有未完成 toolCall | 不重启 | `tail_dirty` |
| 已退出，pane 已关 | 不重启 | `pane_missing` |
| run 记录 / marker / 子 session 缺失 | 不重启 | `session_missing` |

「尾部干净」只看有没有未完成的 toolCall；以 assistant 文本、toolResult、user 或 custom 消息结尾都算干净，不按工具名特判。
